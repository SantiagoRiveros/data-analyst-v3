Temas a cubrir:

-Fundamentos de Numpy y diferencias con listas de Python
-Creacion y manipulacion de Arrays
-Operaciones vectorizadas y funciones matematicas
-Optimizacion: uso de funciones de Numpy para mejorar el rendimiento en calculos

Objetivo:
-Entender que es numpy y porque es preferible usarlo para calculos numericos en vez
de listas de Python

Explicacion:
-Numpy es una libreria especializada en calculos numericos que provee el objeto ndarray
(Array multidimensional)
-Es mucho mas rapido y eficiente que usar listas, sobre todo para operaciones matematicas
y grandes cantidades de datos
-Sus operaciones son vectorizadas, lo que significa que se aplican a todos los elementos
sin necesidad de bucles explcitos.
